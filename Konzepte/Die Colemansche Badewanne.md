# Definition
Ein Makrophänomen A bedingt/verhindert/beeinflusst ein anderes Makrophänomen B
1. Es wirkt auf die individuellen Akteur:innen / sie richten ihre Handlungen danach aus 
2. Die Summe dieser Handlungen konstruiert das Makrophänomen B

# Beispiel
## Makrophänomen A
- Verbreitung des protestantischen Glaubens, insbes. des Glaubens an Prädestination = vorherbestimmte Erwählung oder Verdammnis 
## Individuelles Handeln 
- Prädestinationsangst: Weil niemand weiß, ob er/sie auserwählt ist, wird nach Zeichen gesucht, z.B. Reichtum/Wirtschaftlicher Erfolg 
- Entwicklung eines asketischen Lebensstils, Disziplin, harte Arbeit, Reinvestition von gewinnen -> Reichtum
## Makrophänomen B
- Wenn viele Protestant:innen so handeln, entsteht daraus eine Wirtschaftsordnung -> moderner Kapitalismus
